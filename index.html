About TriageTime

What this is

A free, independent tool that shows hospital waiting times across Australia. No paywall. No signup. No tracking.

Data Sources

  • QLD Live ED: Queensland Health via publicdata.au — CC BY 4.0
  • AU ED (annual): AIHW via publicdata.au — CC BY 4.0
  • AU 4-Hour Rule: AIHW via publicdata.au — CC BY 4.0
  • AU Surgical: AIHW via publicdata.au — CC BY 4.0

How it works

Every day at 06:00 UTC, an automated process downloads the latest CSV files from each source and republishes this site. No database. No server. Just static files.

Limitations

  • QLD live data covers 40 hospitals. Other states publish quarterly.
  • Definitions of "wait time" vary by source.
  • Data is only as fresh as the publisher updates it.

Licence

All data belongs to the respective government publishers. This site is a convenience aggregator. Link back to original sources when citing.
